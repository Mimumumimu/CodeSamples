# CodeSamples

記事で使ったサンプルコードを置いています。  
サンプルごとにフォルダが分かれていて、そのフォルダだけで、ビルドして動かせます。  

| フォルダ | 内容 | 記事 |
|---|---|---|
| [ConPtyTerminal](ConPtyTerminal) | 既存の C# のアプリに、DOS 窓のようなターミナルを足して、ボタンからコマンドを送る。ConPTY と xterm.js を使います。 | [Qiita](https://qiita.com/Mimumumimu/items/faf040f7aacfbe57c966) |

## 使い方

1. 画面右上の「Code」→「Download ZIP」で、zip をダウンロードして、展開します。
2. 使いたいサンプルのフォルダを開きます。
3. フォルダの中の `README.md` に、動かし方が書いてあります。
