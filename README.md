# CodeSamples

記事で使ったサンプルコードを置いています。  
サンプルごとにフォルダが分かれていて、そのフォルダだけで、ビルドして動かせます。  

| フォルダ | 内容 | 記事 |
|---|---|---|
| [ConPtyTerminal](ConPtyTerminal) | 既存の C# のアプリに、DOS 窓のようなターミナルを足して、ボタンからコマンドを送る。ConPTY と xterm.js を使います。Windows フォーム版と WinUI 3 版があります。 | Windows フォーム版: [Qiita](https://qiita.com/Mimumumimu/items/faf040f7aacfbe57c966) / WinUI 3 版: [Qiita](https://qiita.com/Mimumumimu/items/69a1edb0e6af6686f47a) |
| [CredentialManagerSample](CredentialManagerSample) | 既存の C# のアプリで、データベースのパスワードを、設定ファイルに書かず、Windows の資格情報マネージャーに保存する。 | [Qiita](https://qiita.com/Mimumumimu/items/bc9f0de0f46eb42834ec) |

## 使い方

1. 画面右上の「Code」→「Download ZIP」で、zip をダウンロードして、展開します。
2. 使いたいサンプルのフォルダを開きます。
3. フォルダの中の `README.md` に、動かし方が書いてあります。
